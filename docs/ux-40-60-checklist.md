# FINANZZI — UX checklist 40–60

## Objetivo
Uma pessoa que não domina aplicativos financeiros deve conseguir usar o FINANZZI sem treinamento.

## Perguntas para cada tela
- Em poucos segundos fica claro onde a pessoa está?
- A ação principal está explícita?
- O texto usa palavras comuns no dia a dia?
- O usuário precisa escolher algo que o sistema já pode assumir?
- Depois de tocar em algo, fica claro o que aconteceu?
- Se algo falhar, a mensagem explica o próximo passo?
- Os textos importantes têm contraste e tamanho confortáveis?
- Os alvos de toque são fáceis de acertar?

## Linguagem
Preferir “Contas a pagar”, “Quanto posso gastar”, “Registrar” e “Ajuda” a termos técnicos, siglas ou nomes internos.

## Regra de decisão
Não pedir uma informação se o FINANZZI consegue inferir com segurança ou se ela pode ser informada depois.

## Estados
Cada estado vazio deve indicar o próximo passo. Cada loading deve preservar a estrutura da tela. Cada erro deve explicar como seguir. Cada confirmação deve deixar claro o que foi registrado.

## Validação humana
1. Registrar “paguei 80 no mercado”.
2. Descobrir quanto ainda pode gastar.
3. Encontrar uma conta que precisa pagar.
4. Corrigir um lançamento.
5. Encontrar ajuda.
6. Começar a usar o produto sem preencher todos os dados iniciais.
